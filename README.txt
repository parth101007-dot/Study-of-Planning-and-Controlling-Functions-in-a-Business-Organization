POM MICRO PROJECT — PLANNING AND CONTROLLING

Files:
- index.html : Main website
- style.css  : Layout and styling
- script.js  : Navigation, print button, and interactive performance calculator

HOW TO OPEN IN VS CODE (Windows):
1. Extract the ZIP file to a folder.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and select "Open with Live Server".
   Alternatively, double-click index.html in File Explorer to open it in your browser.

CUSTOMIZE BEFORE SUBMISSION:
- Replace the blank student name, class/roll number, and college fields near the conclusion.
- Review the content and adapt it to your teacher's instructions.
- The Sunrise Bakery case is fictional and the sample figures are illustrative.
- Internet is only used for the optional Google Fonts import; the site otherwise works locally.

No npm install or build command is required.
